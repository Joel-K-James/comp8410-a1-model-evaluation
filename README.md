COMP8410 Assignment 1
This project evaluates two proposed systems for fuel-station operations in a Reddy Express case study. It covers promotional image editing, staff assistance, anomaly detection and product recommendations. This repository will contain notebooks, test data, evaluation results and supporting documentation.

The initial environment check was completed in Google Colab using a Tesla T4 GPU with 14.6 GB of memory and PyTorch 2.11.0+cu130.
